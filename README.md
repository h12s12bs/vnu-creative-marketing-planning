## 🌟 課程特色：課堂互動 ✕ 課後 AI 協同實作

針對進修部企管系在職專班同學白天工作、晚上於 **F401 教室** 上課之實務學習情境，本平台特別設計**「課堂即時互動演練 ✕ 課後 Agentic AI 延伸實作」**雙軌學習機制：

### 📱 軌道一：課堂即時互動模式
1. **課堂即時互動工具箱**：老師啟動教學平台後，提供便利的互動面板，同學可直接參與隨堂快測、創意抽卡與個人實務活動。
2. **隨堂 5 題觀念快測**：每週課程重點觀念驗收，學生單手點選即時看詳解，輕鬆驗收當堂核心概念。
3. **行銷企劃靈感抽卡機 (Idea Deck)**：隨機抽取「目標受眾 ✕ 核心痛點 ✕ 行銷科技 ✕ 關鍵情境」4 大元素，同學進行 5 分鐘現場即興個人企劃發想。
4. **創意大轉盤 / 隨機抽籤機**：HTML5 Canvas 物理轉盤，隨機抽籤點名與輪派同學發表，活絡進修部課堂氣氛。
5. **SCAMPER 課堂計時器**：倒數計時與提示音效，引導同學使用紙本便利貼進行 7 步奔馳法腦力激盪，聚焦個人即時研討與創意碰撞！

### 🤖 軌道二：課後延伸實作模式（Agentic AI 行銷企劃工作坊）
學生於課後可自主打開本平台進行深度的 AI 協同練習：
1. **8 大行銷企劃 Agent 實務工坊**：
   - **Agent 1：市場情資與 PESTEL 洞察 Agent**（產業總體趨勢與競品雷達掃描）
   - **Agent 2：STP 受眾定位與 Persona 畫像 Agent**（買家心理痛點與虛擬人物誌刻畫）
   - **Agent 3：SCAMPER 奔馳法創意發想 Agent**（跨界聯名與打破常規活動發想）
   - **Agent 4：爆款社群文案與短影音腳本 Agent**（IG Reels 30 秒分鏡與黃金 3 秒開頭鉤子）
   - **Agent 5：促銷檔期與折扣利潤試算 Agent**（促銷誘因設計、損益兩平與 ROI 精算）
   - **Agent 6：公關危機輿情與回應 Agent**（黃金 3 小時危機公關拆彈與公開聲明擬定）
   - **Agent 7：MarTech 顧客旅程與自動化行銷 Agent**（現代行銷科技工具鏈之自動化獲客與挽回閉環）
   - **Agent 8：行銷企劃全案架構一鍵生成 Agent**（參考行銷企劃十大標準章節，生成一頁式企劃書草案）
2. **ReAct 思考推理視覺化**：擬真終端機介面逐步展現 **Thought (思考) ➔ Action (調用工具) ➔ Observation (環境觀察) ➔ Decision (企劃決策)**，親身體驗新世代 AI 代理人工作思維。
3. **一鍵生成與列印一頁式企劃書**：自訂產品參數後即可生成排版工整之企劃草案，支援列印與 PDF 匯出。
4. **外部 AI 黃金 Prompt 複製庫**：一鍵複製專業結構化提示詞，貼入免費版 ChatGPT、Google Gemini 或 Claude 進行更深入的對話迭代。

   - 自主學習與課堂參與精神 (5%)：個人獨立思考完成專案、積極參與課堂討論與實務演練。

## 🚀 老師上課使用說明（兩種啟動模式）

### 模式一：教學伺服器連線模式 (推薦 👍)
1. 在教師電腦上，直接雙擊點擊 **`啟動教學平台.bat`**。
2. 系統會自動啟動後端伺服器，並開啟瀏覽器至 `http://localhost:5000`。
3. 同學可透過區域網路連線網址，即時參與隨堂測驗、抽卡與轉盤互動。

### 模式二：單機離線免安裝模式 (零網路環境備援)
- 若教室無線網路不穩或無網路，可直接雙擊打開 **`平台首頁(單機離線直接點開).html`**。
- 單一檔案完整內嵌 18 週教學地圖、180 題題庫與 8 大行銷 Agent，在任何電腦與行動裝置瀏覽器皆可 100% 離線運行！
